# Exercise 1: Setting Up JUnit

## Objective
To set up JUnit 4.13.2 in a Java Maven project and create a simple unit test.

## Tools Used
- Java
- Maven
- JUnit 4.13.2
- Visual Studio Code

## Project Structure
- pom.xml
- Calculator.java
- CalculatorTest.java

## Steps Performed
1. Created a Maven Java project.
2. Added the JUnit 4.13.2 dependency in `pom.xml`.
3. Created a `Calculator` class with an `add()` method.
4. Created a `CalculatorTest` class.
5. Wrote a unit test using the `@Test` annotation.
6. Executed the test and verified that it passed successfully.

## Files Included
- pom.xml
- src/main/java/com/example/Calculator.java
- src/test/java/com/example/CalculatorTest.java

## Output
The JUnit test executed successfully without any failures.

## Conclusion
JUnit helps verify that Java methods work correctly. It makes testing easier and helps identify errors during development.

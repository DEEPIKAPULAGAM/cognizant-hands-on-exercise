# Exercise 4: Arrange-Act-Assert (AAA) Pattern

## Objective

To organize JUnit test cases using the Arrange-Act-Assert (AAA) pattern and use setup and teardown methods.

## Tools Used

- Java
- Maven
- JUnit 4.13.2
- Visual Studio Code

## Concepts Used

- Arrange-Act-Assert (AAA) Pattern
- @Before
- @After
- assertEquals()

## Files Included

- Calculator.java
- CalculatorTest.java
- pom.xml

## Output

The test executed successfully using the AAA pattern. The setup method ran before the test, and the teardown method ran after the test.

## Conclusion

The AAA pattern makes test cases easy to understand and maintain. The @Before and @After annotations help initialize and clean up resources automatically.

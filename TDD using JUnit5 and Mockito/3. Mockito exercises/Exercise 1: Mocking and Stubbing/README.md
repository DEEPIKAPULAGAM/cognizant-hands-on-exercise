# Exercise 1: Mocking and Stubbing

## Objective

To learn how to use Mockito to create mock objects and stub method responses for unit testing.

## Tools Used

- Java
- Maven
- JUnit 4.13.2
- Mockito
- Visual Studio Code

## Concepts Used

- Mock Object
- Stubbing
- Mockito
- Unit Testing

## Files Included

- ExternalApi.java
- MyService.java
- MyServiceTest.java
- pom.xml

## Output

The mocked API returned "Mock Data" and the test passed successfully.

## Conclusion

Mockito helps test classes that depend on external services by replacing real objects with mock objects. This allows unit tests to run independently without calling actual external APIs.

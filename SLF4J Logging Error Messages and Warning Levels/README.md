# Exercise 1: Logging Error Messages and Warning Levels

## Objective

To demonstrate logging error and warning messages using SLF4J and Logback.

## Tools Used

- Java
- Maven
- SLF4J
- Logback
- Visual Studio Code

## Files Included

- LoggingExample.java
- pom.xml

## Output

The application logs an error message and a warning message to the console using SLF4J.

## Conclusion

SLF4J provides a simple logging API, while Logback acts as the logging implementation. Logging helps monitor application execution and makes debugging easier.

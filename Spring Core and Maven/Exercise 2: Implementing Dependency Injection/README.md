# Exercise 2: Implementing Dependency Injection

## Objective

To implement Dependency Injection (DI) using Spring IoC Container and XML configuration.

## Tools Used

- Java 17
- Maven
- Spring Core
- Visual Studio Code

## Files Included

- pom.xml
- applicationContext.xml
- BookRepository.java
- BookService.java
- MainApp.java

## Output

Book Service Created

Book Repository Created

## Conclusion

Spring IoC Container injects the BookRepository object into the BookService class using setter injection defined in the XML configuration file.

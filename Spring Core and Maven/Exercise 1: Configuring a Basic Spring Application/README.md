# Exercise 1: Configuring a Basic Spring Application

## Objective

To configure a basic Spring application using Maven and XML-based bean configuration.

## Tools Used

- Java 17
- Maven
- Spring Core
- Visual Studio Code

## Files Included

- pom.xml
- applicationContext.xml
- BookRepository.java
- BookService.java
- MainApp.java

## Output

Book Service Created

Book Repository Created

## Conclusion

This exercise demonstrates how to configure Spring beans using an XML configuration file and load them using the Spring Application Context.

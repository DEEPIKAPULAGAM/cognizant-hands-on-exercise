# Exercise 3: Assertions in JUnit

## Objective
To understand and use different JUnit 4.13.2 assertions for validating test results.

## Tools Used
- Java
- Maven
- JUnit 4.13.2
- Visual Studio Code

## Assertions Used
- assertEquals()
- assertTrue()
- assertFalse()
- assertNull()
- assertNotNull()

## Files Included
- pom.xml
- AssertionsTest.java

## Output
All assertions executed successfully and the test passed without any failures.

## Conclusion
JUnit assertions help verify expected results during testing. They are useful for validating conditions, comparing values, and checking objects.

# Spring REST using Spring Boot 3 - Project Setup

## Objective

The objective of this exercise is to create a Spring Boot web project using Maven and understand the basic project structure.

## Technologies Used

- Java
- Spring Boot 4
- Spring Web
- Spring Boot DevTools
- Maven

## Project Structure

- `src/main/java` - Application source code
- `src/main/resources` - Configuration files
- `src/test/java` - Test classes
- `pom.xml` - Maven configuration

## Features

- Created a Spring Boot web project.
- Added Spring Web and DevTools dependencies.
- Successfully started the embedded Tomcat server.
- Verified the application using log messages.

## Output

```
Tomcat started on port 8080 (http)
Started SpringLearnApplication
Application Started Successfully
```

## Learning Outcomes

- Learned the structure of a Spring Boot project.
- Understood the purpose of `@SpringBootApplication`.
- Learned the role of `pom.xml`.
- Successfully ran a Spring Boot web application.
